# 🐳 Docker Setup Guide (DOCKER_SETUP.md)

This document explains how to set up a new PC (based on Ubuntu 24.04) from scratch to run this project using Docker with GPU (NVIDIA graphics card) support enabled.

## 📋 Prerequisites

Before installing Docker, ensure your system has the NVIDIA drivers installed. You can verify this by running:
```bash
nvidia-smi
```
*(If it doesn't show a table with your GPU stats, install the drivers first with `sudo ubuntu-drivers autoinstall` and reboot the PC).*

---

## 🛠️ Phase 1: Correct Docker Installation

> **⚠️ IMPORTANT:** Do not use the Snap version of Docker (`sudo snap install docker`), as its isolated environment prevents the container from properly communicating with the GPU. If it is already installed, remove it with: `sudo snap remove docker`.

**1. Set up Docker's official repository:**
```bash
sudo apt-get update
sudo apt-get install ca-certificates curl
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc

echo \
  "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.asc] https://download.docker.com/linux/ubuntu \
  $(. /etc/os-release && echo "$VERSION_CODENAME") stable" | \
  sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
```

**2. Install Docker and Docker Compose:**
```bash
sudo apt-get update
sudo apt-get install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
```

**3. Configure permissions (To avoid using `sudo` for every command):**
To avoid `permission denied while trying to connect to the docker API` errors, add your user to the Docker group:
```bash
sudo usermod -aG docker $USER
newgrp docker
```

## 🎮 Phase 2: GPU Support (NVIDIA Container Toolkit)

For Docker to use the graphics card, we need to install this communication bridge.

**1. Add the NVIDIA repository:**
```bash
curl -fsSL https://nvidia.github.io/libnvidia-container/gpgkey | sudo gpg --dearmor -o /usr/share/keyrings/nvidia-container-toolkit-keyring.gpg \
  && curl -s -L https://nvidia.github.io/libnvidia-container/stable/deb/nvidia-container-toolkit.list | \
    sed 's#deb https://#deb [signed-by=/usr/share/keyrings/nvidia-container-toolkit-keyring.gpg] https://#g' | \
    sudo tee /etc/apt/sources.list.d/nvidia-container-toolkit.list
```

**2. Install the Toolkit and restart Docker:**
```bash
sudo apt-get update
sudo apt-get install -y nvidia-container-toolkit
sudo nvidia-ctk runtime configure --runtime=docker
sudo systemctl restart docker
```

*(To check if it works, you can run: `docker run --rm --runtime=nvidia --gpus all ubuntu nvidia-smi`. It should display your GPU info).*

---

## 🚀 Phase 3: Build the Image and Run the Container

Once the PC environment is ready, follow these steps to get the project up and running.

**1. Build and start the container:**
Navigate to the project folder (where the `docker-compose.yml` is located) and run:
```bash
docker compose up -d
```
*Note: The `-d` flag starts the container in the background (detached mode). If this is the first time, this command will automatically download dependencies and build the `fish_sizing-dev` image.*

**2. Enter the container interactively:**
To run scripts or work inside the container, you need to open a terminal (bash) inside it. The container name generated by Compose is `fish_3d-fish_sizing_u22`.

Run the following command to enter:
```bash
docker exec -it fish_3d-fish_sizing_u22 bash
```

**3. Stop the container:**
When you finish working, you can stop the container (without deleting its configuration) with:
```bash
docker compose down
```

---

### 💡 Extra tips:
- You can view container logs in real-time with: `docker logs -f fish_3d-fish_sizing_u22`
- If you make changes to the Dockerfile or need to rebuild the image from scratch, use: `docker compose up -d --build`
